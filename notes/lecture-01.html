Lecture 01：Getting Started

第一堂课课堂笔记

1. 课程结构与学习方式（Course Logistics）

本课程不仅讲授理论知识，更强调实践能力。

核心要求包括：

  • 使用 GitHub 管理学习过程
  • 定期备份（Backup your work）
  • 使用 Markdown 进行结构化记录
  • 学习 Linux、R、Python 等工具

课程强调：

不只是运行软件，而是理解分析流程。

2. 什么是生物信息学？（Big Data-driven）

课程提出：

生命系统可以被视为信息系统。

DNA / RNA 序列是生命的“语言”，
生物信息学的目标是解读这种语言。

生物信息学分析的基本流程包括：

  1. Question（提出问题）
  2. Information（获取数据）
  3. Analysis（数据处理）
  4. Modeling（建模与计算）

这说明：

  • 生物问题 → 数据问题 → 数学问题 → 计算问题

3. Algorithm 与 Model 的区别（重点）

在分析流程的最后阶段，课件中同时出现：

Probabilistic Model & Computational Algorithm

这表明两者相关，但并不相同。

3.1 Model（模型）

Model 用于描述数据结构与关系。

  • 描述数据的结构
  • 表达变量之间的关系
  • 给出对现实的数学假设

模型回答的问题是：

数据“应该如何被理解”？

在机器学习部分，课件提到：

  • 线性模型
  • 逻辑回归
  • 神经网络

这些都是对数据关系的假设结构。

3.2 Algorithm（算法）

Algorithm 用于执行计算过程。

  • 在模型框架下进行计算
  • 求解参数
  • 得到预测结果

算法回答的问题是：

在这个模型假设下，如何计算？

例如：

  • 迭代计算
  • 优化过程
  • 计算步骤

模型强调”结构”，算法强调”过程”。

3.3 二者对比

核心差异：模型回答“如何描述”，算法回答“如何计算”。

方面 Model Algorithm
本质 数学结构 计算步骤
关注点 数据关系 求解过程
作用 描述与假设 计算与实现

3.4 二者关系

模型定义分析框架，
算法在该框架下执行计算。

在生物信息学中：

  • 先建立对生物数据的假设模型
  • 再设计或选择算法进行求解

二者缺一不可。

4. 生物信息学与大数据

课件强调：

  • 高通量测序（NGS）
  • 大规模基因组计划
  • 多组学数据

特点：

  • 数据规模大
  • 数据结构复杂
  • 需要计算方法支持

因此：

生物信息学是数据驱动的学科。

5. 本节课核心理解

  • 生物信息学是 问题驱动 + 数据驱动 的学科。
  • 模型 决定分析框架。
  • 算法 决定计算实现。
  • 课程强调实践与工具能力。

6. 本学期学习目标与规划

6.1 对课程内容的理解

本课程围绕生物信息学的基本分析流程展开：

  • 从生物问题出发
  • 获取与整理数据
  • 建立模型
  • 通过算法进行计算分析

课程内容将涉及：

  • 生物数据类型与特征
  • 基本统计与机器学习思想
  • 模型与算法的关系
  • 实践工具（Linux、R 等）

6.2 本学期能力目标

结合课程要求，我希望重点提升以下能力：

（1）Linux 使用能力

  • 熟悉基本命令（ls, cd, grep 等）
  • 理解文件系统结构
  • 能在终端完成基础数据处理

（2）R 语言能力

寒假曾接触 R，但基础薄弱。

本学期希望：

  • 理解数据结构与基本语法
  • 掌握数据整理与可视化方法
  • 能够完成简单的统计分析任务

6.3 长期学习方向（Continue Learning）

在完成课程基本要求的基础上，我希望进一步：

  • 深入理解统计模型与机器学习方法
  • 学习更系统的数据分析流程
  • 将模型与算法思维应用到真实生物数据问题中

目标是从“会使用工具”逐步过渡到“理解分析框架”。
